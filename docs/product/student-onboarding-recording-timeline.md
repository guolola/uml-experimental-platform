# UML 平台学生入门录制时间表与字幕稿

## 使用方式

- 成片建议时长：10-11 分钟。
- 录制方式：按片段录制，生成等待只保留 3-5 秒。
- Recordly 设置：只录浏览器项目窗口，开启鼠标轨迹、点击高亮和鼠标点击音效，关闭麦克风。
- 配音方式：后期用 AI 配音，字幕文本可直接作为配音稿使用。
- 案例项目：`图书馆座位预约系统`。

## 示例需求文本

```text
图书馆座位预约系统允许学生登录后查询空闲座位，按日期和时间段提交预约。
系统需要校验登录状态、座位可用性，并防止同一学生在同一时间段重复预约。
预约成功或取消后发送站内通知。
管理员可以维护座位、查看预约记录，并在学生未到场或设备故障时取消预约。
系统需要记录预约状态、座位位置、取消原因和操作时间，并支持移动端查看。
```

## 字幕分段稿

### 00:00-00:35 开场

今天我们用“图书馆座位预约系统”这个小案例，完整走一遍 UML 实验平台的学生使用流程。我们会从创建项目开始，依次完成需求规则、需求 UML、设计模型、代码原型和说明书。

### 00:35-01:30 创建项目和选择 Provider

项目是本次实验的工作空间。后面的需求文本、模型、代码、运行历史和说明书都会保存在这里。默认模型策略选择课程或系统分配的免费托管 Provider，后续生成任务都会优先使用它。

### 01:30-02:20 输入需求并生成规则

进入需求页后，把自然语言需求粘贴进去。平台会把一整段需求拆成一条条结构化规则。需求规则不是简单摘要，它是后续 UML、设计、代码和说明书共同使用的输入契约。

### 02:20-03:35 检查和编辑需求规则

生成完成后，可以在需求规则表里检查每条规则。这里可以搜索，也可以按类型筛选。需求文本可以直接编辑，如果某条规则太模糊，就补充角色、触发条件、输入输出或异常处理。

### 03:35-04:20 AI 修复和人工确认

如果规则旁边出现待确认提示，可以打开详情查看平台认为缺少什么。智能修复会给出候选结果，但不要盲目采纳。合理就采纳，不合理就拒绝，也可以回到表格手动修改。最终确认需求的人是你。

### 04:20-05:10 生成需求 UML

需求规则确认后，就可以生成需求阶段模型。常见模型包括用例模型、领域概念模型、总体业务流程、部署需求模型和原型界面关系。如果缺少前置映射或上游模型，平台会尝试自动补齐，并在提示或运行记录中留下痕迹。

### 05:10-06:20 查看需求模型详情

模型生成后，不要只看图片。详情页里可以查看 SVG 图，也可以查看结构化元素和关系。追踪矩阵会说明模型元素来自哪条需求规则，所以模型是可检查、可追踪的。

### 06:20-06:55 手动校正模型

如果模型里有不准确的元素或关系，可以手动校正。确认编辑后，平台会保存当前模型草稿，并自动更新当前图。也就是说，AI 生成的是初稿，学生仍然可以继续修正。

### 06:55-07:45 生成设计模型和映射规则

接下来进入设计页。设计模型是在需求模型基础上继续推导的。简单记住几条映射规则：用例模型会推导到用例实现设计和界面关系；领域概念模型会支撑设计类图和数据库设计；业务流程会帮助生成架构和组件关系；部署需求会推导部署设计。

### 07:45-08:35 查看设计模型详情

设计模型回答的是需求里的业务元素如何落到类、服务、数据库、组件和页面流程上。它和需求模型一样，可以查看来源、检查结构，也可以人工调整。调整后，下游代码和说明书建议重新生成。

### 08:35-09:20 生成代码原型

代码页会根据设计模型和界面关系生成前端原型。左侧看文件树，中间看代码，右侧看预览。这里重点不是直接得到最终产品，而是快速验证页面流程和业务状态。

### 09:20-10:10 生成和下载说明书

最后进入说明书页。这里可以生成需求规格说明书，也可以生成软件设计说明书。生成后可以在项目中打开编辑器查看，也可以下载 DOCX 用于课程提交。文档列表会保留版本、更新时间和下载状态。

### 10:10-10:50 运行历史和重试

如果生成失败，不需要在教程里排查技术细节。可以从运行历史里查看阶段和错误，并点击重试或重新运行。这样一次实验不仅有结果文件，也有完整的生成过程和可复盘证据。

### 10:50-11:10 收尾

到这里，我们已经完成从需求文本到需求规则、UML、设计模型、代码原型和说明书的完整链路。学生可以按照这个流程独立完成一次课程实验。

## 拍摄注意事项

- 每段开头先让鼠标静止 1 秒，再开始点击。
- 每次点击前停 0.5 秒，点击后停 1 秒，方便后期对齐字幕和点击声。
- 点击“生成”后只保留 3-5 秒任务进度，长等待剪掉。
- 不要放大 API Key、私人邮箱、密码管理器、聊天窗口或无关项目。
- 如果某个生成任务临时失败，短暂展示“重试”入口，然后切到已完成的材料项目继续拍。
- 如果说明书在线编辑器不可用，就展示下载 DOCX 能力。
- 如果没有待确认的 AI 修复项，就用需求规则表的手动编辑和新增需求项说明同一概念。
