# 项目首页与项目创建

## 适用场景

你需要找到已有项目、创建新的实验项目，或确认项目成员、课程归属和默认模型策略是否正确。

## 入口位置

- 顶部导航“项目”进入项目首页。
- 项目首页的“新建项目”进入创建表单。
- 项目卡片点击“进入项目”打开项目工作台。

## 前置条件

你需要登录，并且账号已被加入课程、班级或项目。如果项目列表为空，先确认是否使用了正确邮箱，或让项目管理员重新邀请。

## 操作步骤

1. 打开[项目首页](/projects)，查看项目卡片。
2. 检查项目名称、成员数、更新时间、最近生成时间和状态。
3. 点击“新建项目”，填写项目名称、描述、可见性、课程/班级/team 和默认模型策略。
4. 创建后进入项目工作台，确认顶部显示项目名称和权限。
5. 需要调整成员或策略时，打开项目工作台右侧的项目设置或成员抽屉。

## 输入示例

![创建项目表单截图](/help/images/docs-project-create.png)

| 字段 | 示例 |
| --- | --- |
| 项目名称 | 图书馆预约系统 |
| 项目描述 | 面向学生和管理员的座位预约课程实验 |
| 可见性 | team |
| 默认模型策略 | 课程 OpenAI 托管配置 |

## 预期输出

创建完成后会得到一个项目空间。这个项目会绑定成员权限、运行历史、文档、默认模型策略和工作台状态。后续所有需求、UML、设计、代码、测试和说明书都沉淀在这个项目里。

## 映射关系

| 项目字段 | 影响范围 |
| --- | --- |
| 项目名称 | 顶部栏、运行历史、说明书标题 |
| 成员角色 | 是否能管理成员、设置、危险操作 |
| 默认 Provider | 工作台生成任务使用的托管模型 |
| 课程/班级/team | 项目归属和教学管理 |

## 常见问题与处理

- 看不到项目：确认登录邮箱是否与邀请邮箱一致。
- 无法创建项目：检查是否缺少课程/team 归属或默认模型策略。
- 进入项目后显示权限不足：当前账号不是项目成员。
- 默认模型不可用：从顶部账号入口进入全局设置，或在项目设置中检查项目默认 Provider。
