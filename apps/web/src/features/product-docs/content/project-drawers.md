# 项目抽屉：设置、成员、任务、历史与文档

## 适用场景

你想在不离开工作台的情况下管理项目、成员、生成任务、运行历史和文档记录。

## 入口位置

项目工作台顶部右侧快捷按钮，或移动端“打开项目操作”菜单。

![项目抽屉截图](/help/images/docs-project-drawers.png)

## 前置条件

当前账号需要是项目成员。项目设置和成员管理可能要求 owner 或 editor 权限。

## 操作步骤

![项目设置抽屉截图](/help/images/docs-project-settings.png)

1. 点击“项目设置”查看项目名称、归属、模型策略和危险操作。
2. 点击“成员”邀请成员、调整角色、重发或撤销邀请。
3. 点击“生成任务”查看当前运行阶段。
4. 点击“运行历史”查看过去任务、恢复快照、重试或删除记录。
5. 点击“文档中心”查看三类已生成说明书、版本、在线编辑和下载状态。

![成员管理抽屉截图](/help/images/docs-project-members.png)

![项目文档中心抽屉截图](/help/images/docs-project-documents.png)

## 输入示例

| 操作 | 示例 |
| --- | --- |
| 邀请成员 | editor@example.edu，角色 editor |
| 调整模型策略 | 默认 Provider 改为课程托管配置 |
| 复盘失败任务 | 打开运行历史 -> 查看错误 |

## 预期输出

| 抽屉 | 输出 |
| --- | --- |
| 项目设置 | 项目信息、课程/team、默认 Provider、留存策略 |
| 成员 | 成员列表、邀请状态、角色 |
| 生成任务 | 阶段进度、子任务、错误和执行详情 |
| 运行历史 | 快照、重试、恢复、删除 |
| 文档中心 | 需求规格说明书、软件设计说明书、可行性研究报告、版本、编辑锁和下载状态 |

## 映射关系

项目抽屉不是单独阶段，而是围绕同一个项目空间管理元数据和证据。成员影响权限，项目设置影响生成策略，任务和历史影响复盘，文档中心影响交付。

## 常见问题与处理

- 按钮不可用：当前角色没有权限。
- 成员收不到邀请：检查邮箱和邀请状态，必要时重发。
- 运行历史为空：说明项目尚未完成可保存的生成任务。
