# 账号设置与全局模型配置

## 适用场景

你需要修改个人资料、检查登录会话、启用 MFA，或选择生成任务使用的托管 Provider 和默认模型。

## 入口位置

顶部右侧账号按钮 -> 设置弹窗 -> 全局设置。

![账号全局设置截图](/help/images/docs-account-global-settings.png)

## 前置条件

账号必须登录。未登录时只能看到前往登录提示，不能保存模型配置。

## 操作步骤

1. 点击顶部账号入口。
2. 打开“全局设置”。
3. 在“模型托管配置”里选择课程或个人 Provider。
4. 选择默认模型。
5. 点击“测试托管配置”，确认可用。
6. 点击保存。

## 输入示例

| 字段 | 示例 |
| --- | --- |
| 托管 Provider 配置 | 课程 OpenAI 托管配置 |
| 默认模型 | gpt-5.5 |
| 字号 | 默认 |
| 显示过期模型横幅 | 开启 |

## 预期输出

保存后，工作台生成任务会读取当前账号的 Provider 偏好。若项目设置绑定了项目默认 Provider，项目策略优先。

## 映射关系

| 设置项 | 影响 |
| --- | --- |
| 托管 Provider | 需求、UML、设计、代码、测试、说明书生成 |
| 默认模型 | 每次生成的默认模型选择 |
| 工作台偏好 | 主题、字号和自动生成行为 |
| MFA | 登录和高危操作安全 |

## 常见问题与处理

- 没有 Provider：联系教师或管理员分配托管配置。
- 测试失败：查看错误消息，常见原因是供应商额度、模型名称或网络问题。
- 找不到独立模型配置页面：该入口已经取消，只能从账号弹窗进入全局设置。
