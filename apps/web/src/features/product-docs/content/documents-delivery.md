# 说明书生成、样式、版本与下载

## 适用场景

你需要生成需求规格说明书、软件设计说明书或可行性研究报告，调整样式，在线编辑，查看版本并下载或复用文档。

## 入口位置

工作台左侧“说明书”，或项目抽屉“文档中心”。

![说明书生成截图](/help/images/docs-documents.png)

## 前置条件

不同模板使用不同前置产物：需求规格说明书依赖当前需求产物，软件设计说明书依赖设计产物，可行性研究报告只依赖当前有效的上下文图和实现方案。模型图缺失时文档会保留提示。

## 操作步骤

1. 打开说明书页。
2. 选择说明书类型：需求规格说明书、软件设计说明书或可行性研究报告。
3. 打开“说明书样式”调整标题、页眉、字号等。
4. 点击生成说明书。
5. 生成完成后在当前页面或文档中心查看版本、下载状态和编辑锁，并可用 OnlyOffice 在线编辑。

## 输入示例

| 说明书类型 | 主要内容 |
| --- | --- |
| 需求规格说明书 | 需求文本、规则、需求 UML、追踪 |
| 软件设计说明书 | 设计模型、架构、类图、数据库、接口 |
| 可行性研究报告 | 补充资料、上下文图、候选方案、推荐依据、成本收益、风险和五类结论 |

## 预期输出

| 输出 | 说明 |
| --- | --- |
| DOCX 文件 | 可下载提交 |
| 文档版本 | 每次生成保留版本 |
| 下载状态 | 确认文件是否可用 |
| 编辑锁 | OnlyOffice 编辑状态 |

## 映射关系

| 上游产物 | 说明书内容 |
| --- | --- |
| 需求规则 | 需求条目和约束 |
| PlantUML/SVG | 图表章节 |
| 追踪矩阵 | 覆盖说明 |
| 设计模型 | 架构、类图、数据库设计 |
| 可行性上下文与实现方案 | 可行性研究报告的分析依据、推荐方案和结论 |

## 常见问题与处理

- 说明书缺图：回到图或设计页补齐 SVG。
- 可行性研究报告不可生成：根据模板附近提示返回可行性分析；上下文过期时重建两个产物，仅实现方案过期时只重建实现方案。
- 下载不可用：查看文档中心状态，必要时重新生成。
- 版本太多：通过文档中心查看最新版本和历史版本。
