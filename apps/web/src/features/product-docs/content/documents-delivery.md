# 说明书生成、样式、版本与下载

## 适用场景

你需要生成需求规格说明书或软件设计说明书，调整样式，查看版本，下载或复用文档。

## 入口位置

工作台左侧“说明书”，或项目抽屉“文档中心”。

![说明书生成截图](/help/images/docs-documents.png)

## 前置条件

说明书依赖需求规则、UML 图、设计模型和成功渲染的 SVG。缺图时文档会保留提示。

## 操作步骤

1. 打开说明书页。
2. 选择说明书类型：需求规格说明书或软件设计说明书。
3. 打开“说明书样式”调整标题、页眉、字号等。
4. 点击生成说明书。
5. 生成完成后在文档中心查看版本、下载状态和编辑锁。

## 输入示例

| 说明书类型 | 主要内容 |
| --- | --- |
| 需求规格说明书 | 需求文本、规则、需求 UML、追踪 |
| 软件设计说明书 | 设计模型、架构、类图、数据库、接口 |

## 预期输出

| 输出 | 说明 |
| --- | --- |
| DOCX 文件 | 可下载提交 |
| 文档版本 | 每次生成保留版本 |
| 下载状态 | 确认文件是否可用 |
| 编辑锁 | OnlyOffice 编辑状态 |

## 映射关系

| 上游产物 | 说明书内容 |
| --- | --- |
| 需求规则 | 需求条目和约束 |
| PlantUML/SVG | 图表章节 |
| 追踪矩阵 | 覆盖说明 |
| 设计模型 | 架构、类图、数据库设计 |

## 常见问题与处理

- 说明书缺图：回到图或设计页补齐 SVG。
- 下载不可用：查看文档中心状态，必要时重新生成。
- 版本太多：通过文档中心查看最新版本和历史版本。
