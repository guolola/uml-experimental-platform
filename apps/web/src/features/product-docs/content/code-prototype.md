# 代码原型生成与预览

## 适用场景

设计模型已生成，你想把需求和设计上下文转成可运行的 React 原型，并检查页面流程、业务断言和质量诊断。

## 入口位置

- 工作台左侧“代码”。
- 代码页顶部“启动生成”“重新生成”“导出”。
- 右侧预览区域和文件树。

![代码文件树和预览截图](/help/images/docs-code-preview.png)

## 前置条件

至少需要设计模型。若设计阶段失败，代码页会显示前置条件原因，而不是只禁用按钮。

## 操作步骤

1. 打开代码页，确认设计模型数量和代码状态。
2. 点击“启动生成”。
3. 生成过程中观察文件树、预览状态和生成任务。
4. 预览编译失败时，根据错误定位文件。
5. 查看质量诊断，确认业务流程、状态流转、边界条件是否覆盖。
6. 需要提交或复盘时导出代码快照或运行报告。

## 输入示例

代码生成会读取这些上游内容：

| 上游内容 | 示例 |
| --- | --- |
| 需求规则 | 学生不能重复预约同一时间段 |
| 设计模型 | ReservationService、SeatRepository、预约页 |
| 界面关系 | 首页 -> 查询座位 -> 提交预约 -> 结果页 |

## 预期输出

| 输出 | 说明 |
| --- | --- |
| 文件树 | React 页面、组件、样式和模拟数据 |
| 预览 | 在浏览器内查看生成界面 |
| 质量诊断 | 页面数量、组件数量、业务断言覆盖 |
| 业务断言 | 例如重复预约错误、空状态、加载失败 |

## 映射关系

| 设计产物 | 代码产物 |
| --- | --- |
| 界面关系图 | 页面路由和导航流程 |
| 设计类图 | 类型、服务和数据结构 |
| 用例实现设计 | 页面交互和状态转换 |
| 数据库设计 | 模拟数据和表格字段 |

## 常见问题与处理

- 预览空白：先看预览区域错误，再打开生成任务中的代码验证阶段。
- 文件缺入口：重新生成或检查 `codeEntryFile` 是否写入。
- 业务覆盖不足：查看质量诊断中的失败断言，补充需求后重新生成。
- 生成仍在修复：预览可能已可用，但质量检查还在完善输出。
