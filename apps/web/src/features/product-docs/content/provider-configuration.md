# 配置 Provider

## 适用场景

你想使用自己的模型供应商、自己的 API Key，或想使用推荐榜里的国外模型。

## 入口位置

顶部右侧账号按钮 -> 设置弹窗 -> 全局设置 -> 模型托管配置 -> 添加供应商。

![账号全局设置入口](/help/images/docs-account-global-settings.png)

## 先理解权益规则

| Provider 类型 | 是否消耗平台次数 | 说明 |
| --- | --- | --- |
| 个人自配 Provider | 不消耗 | 使用你自己的 Base URL 和 API Key，供应商费用由你自己的账号承担 |
| 系统 Provider | 消耗 | 使用平台托管资源，需要购买次数包 |
| 项目 Provider | 消耗 | 由项目或课程配置，项目生成任务优先使用 |

邮箱验证后，系统会初始赠送 10 次权益。赠送权益有有效期；页面展示的剩余次数和有效期以账号权益与账单结果为准。

## 添加个人 Provider

1. 点击顶部右侧账号按钮。
2. 打开“设置”。
3. 进入“全局设置”。
4. 在“模型托管配置”区域点击“添加供应商”。
5. 填写供应商名称、Base URL 和 API Key。
6. 点击“获取模型列表”，等待系统拉取并探测可用模型。
7. 选择默认模型。
8. 点击“测试托管配置”。
9. 测试通过后点击“添加供应商”。
10. 回到全局设置页，确认 Provider 和默认模型已选中，再点击“保存”。

## 配置截图

全局设置入口在账号设置弹窗里，模型配置区域会展示当前 Provider、默认模型和权益提示。

![账号全局设置入口](/help/images/docs-account-global-settings.png)

添加供应商时，需要先填写 Base URL 和 API Key。只有获取到模型列表后，默认模型下拉框才会可选。

![添加供应商表单](/help/images/docs-provider-configuration.png)

模型列表获取成功后，默认模型下拉框会显示可选模型；测试通过后，默认模型下方会出现“测试已通过”，此时才能添加或保存供应商。

## 字段说明

| 字段 | 填写建议 |
| --- | --- |
| 名称 | 写成自己能识别的名称，例如“我的 SiliconFlow” |
| Base URL | 填供应商提供的 OpenAI-compatible 接口地址 |
| API Key | 填自己的密钥，页面不会回显已保存密钥 |
| 默认模型 | 从“获取模型列表”返回的模型里选择 |

## 预期输出

| 操作 | 结果 |
| --- | --- |
| 获取模型列表 | 返回可用聊天模型，并探测结构化输出能力 |
| 测试托管配置 | 使用默认模型发起一次临时连接测试 |
| 添加供应商 | 创建仅当前账号可用的 Provider |
| 保存全局设置 | 后续生成任务默认使用该 Provider 和模型 |

## 常见问题与处理

- 按钮不能点：先确认 Base URL 和 API Key 已填写。
- 获取不到模型：检查 Base URL 是否是模型接口根地址，API Key 是否有效，供应商是否支持模型列表接口。
- 测试失败：优先看错误提示，常见原因是模型不可用、密钥无权限、供应商额度不足或网络失败。
- 添加供应商按钮仍不可用：需要先获取模型列表，并通过“测试托管配置”。
- 想用国外模型：必须自己添加支持该模型的 Provider；系统 Provider 只提供国产模型。
- 想避免消耗平台次数：选择个人自配 Provider；系统或项目 Provider 会消耗平台权益。
