# 生成任务、运行历史与证据复盘

## 适用场景

你需要观察生成进度、查看失败阶段、重试任务、恢复历史快照，或导出一次生成的证据。

## 入口位置

- 项目工作台顶部“生成任务”。
- 项目抽屉“运行历史”。

![生成任务截图](/help/images/docs-generation-task.png)

## 前置条件

至少启动过一次需求、设计、代码或说明书生成。运行中任务会实时显示，完成后进入运行历史。

## 操作步骤

1. 生成时打开“生成任务”。
2. 查看阶段：抽取需求规则、生成模型、生成 PlantUML、渲染 SVG、代码检查等。
3. 如果失败，查看错误消息和可重试子任务。
4. 任务结束后打开运行历史。
5. 对历史记录执行恢复快照、重新运行、重新下载或导出报告。

![运行历史截图](/help/images/docs-run-history.png)

## 输入示例

```text
需求模型生成失败：PlantUML 编译失败，正在尝试修复（1/2）。
```

## 预期输出

| 位置 | 你能看到 |
| --- | --- |
| 生成任务 | 当前阶段、子任务数量、队列、错误、执行详情 |
| 运行历史 | 历史快照、创建时间、模型、状态、操作 |
| 导出报告 | Markdown 运行报告和快照 JSON |

## 映射关系

| 运行阶段 | 关联页面 |
| --- | --- |
| extract_rules | 需求页规则列表 |
| generate_models | UML 或设计模型页 |
| generate_plantuml / render_svg | 图表页和模型详情页 |
| generate_code_files | 代码页文件树 |
| generate_document_text / render_document_file | 说明书页 |

## 常见问题与处理

- 卡在排队：查看队列原因和前方模型调用数。
- 单个模型失败：在生成任务里重试此模型。
- 历史记录恢复后页面没变化：确认恢复的是当前项目和当前阶段快照。
- 错误太技术化：先看阶段名称，再回到对应页面找用户提示。
