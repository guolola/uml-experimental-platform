# 生成、渲染与修复排障

## 适用场景

你遇到生成失败、图表渲染失败、AI 修复失败、可行性产物过期、模型不可用、说明书缺图、支付恢复失败或权限不足，需要快速定位问题。

## 入口位置

- 当前页面的按钮附近提示。
- 项目顶部“生成任务”。
- 项目抽屉“运行历史”。
- 账号入口“全局设置”。

![排障截图](/help/images/docs-troubleshooting.png)

## 前置条件

先确认你知道失败发生在哪个阶段：系统需求、可行性分析、需求模型、UML、设计模型、代码、测试、说明书、权益购买或项目管理。

## 操作步骤

1. 先看当前按钮附近的阻塞原因。
2. 打开生成任务，定位失败阶段。
3. 如果任务已结束，打开运行历史查看错误和快照。
4. 回到对应页面修复输入或重试单个模型。
5. 如果是权限或模型问题，检查账号设置、项目设置和成员角色。

## 输入示例

```text
错误：PlantUML repair failed
阶段：render_svg:deployment
处理：打开部署需求模型，查看 PlantUML 源码和渲染错误，重试此模型。
```

## 预期输出

| 问题 | 优先查看 |
| --- | --- |
| 生成按钮不可用 | 按钮附近原因 |
| 模型生成失败 | 生成任务子任务 |
| SVG 渲染失败 | PlantUML 源码和 diagramErrors |
| AI 修复失败 | 修复候选错误消息 |
| 可行性报告被阻止 | 上下文图和实现方案的新鲜度提示 |
| 说明书缺图 | 图表页 SVG 状态 |
| 继续支付失败 | 账户账单中的订单状态和有效期 |
| 权限不足 | 成员角色和项目设置 |

## 映射关系

排障要按“页面提示 -> 生成任务 -> 运行历史 -> 上游页面”走。不要直接重跑全部流程，先定位失败产物，再只修复对应阶段。

## 常见问题与处理

- 模型不可用：从顶部账号入口进入全局设置，测试托管 Provider。
- 队列等待太久：查看生成任务里的队列原因。
- 修复一直失败：手动简化需求或模型，再重新生成。
- 可行性实现方案过期：若上下文仍有效，只重新生成实现方案；不要无条件重跑两个产物。
- 有未保存的实现方案：先保存，或确认放弃草稿后再重新生成。
- 待支付订单不能继续：已过期或非待支付订单需要重新创建。
- 运行历史没有记录：任务可能未完成到可保存状态。
