# 项目工作台：顶部栏、侧边栏与标签页

## 适用场景

你进入项目后，需要理解顶部栏、侧边栏、标签页、移动端导航和工作台状态如何配合。

## 入口位置

从项目首页进入任意项目后即可看到项目工作台。

![项目工作台截图](/help/images/docs-workspace-shell.png)

## 前置条件

账号必须是项目成员。不同角色会影响项目设置和成员管理能力，但查看大部分工作台内容不受影响。

## 操作步骤

1. 左侧侧边栏选择系统需求、可行性分析、需求模型、图、设计模型、代码、测试、说明书。
2. 打开的页面会出现在标签页中。
3. 对同一模型重复打开时会复用已有标签页。
4. 点击顶部“链路图”查看跨阶段关系。
5. 点击顶部“生成任务”查看当前任务状态。

## 输入示例

```text
我要同时看“用例模型”和“设计类图”：先在图分组打开用例模型，再在设计分组打开设计类图，两个页面会出现在标签页。
```

## 预期输出

| UI 区域 | 作用 |
| --- | --- |
| 顶部栏 | 项目状态、生成任务、链路图、账号入口 |
| 侧边栏 | 工作台阶段和模型树 |
| 标签页 | 多页面切换和关闭 |
| 移动导航 | 小屏下的阶段入口 |

## 映射关系

| 标签类型 | 对应产物 |
| --- | --- |
| 系统需求 | 需求文本、规则、质量报告和需求基线 |
| 可行性分析 | 上下文图、实现方案、成本收益、风险与结论 |
| 需求模型 | 需求阶段结构化模型 |
| 图 | 需求模型、PlantUML、SVG、元素 |
| 设计模型 | 设计模型、设计追踪 |
| 代码 | 文件树、预览、质量诊断 |
| 测试 | 测试用例和覆盖关系 |
| 说明书 | 三类 DOCX、在线编辑和文档版本 |

## 常见问题与处理

- 侧边栏模型没有出现：先确认对应阶段是否生成成功。
- 标签页太多：关闭当前阶段其他标签。
- 移动端找不到侧边栏：使用底部或顶部的移动导航入口。
