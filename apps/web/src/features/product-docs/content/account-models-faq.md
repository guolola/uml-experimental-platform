# 账号、模型配置与权限问题

## 适用场景

你遇到登录、项目权限、模型配置、生成权益或账号安全问题，需要知道从哪里检查。

## 入口位置

- 顶部账号按钮：个人资料、安全设置、登录会话、全局设置。
- 顶部账号入口 -> 全局设置：选择托管 Provider 和默认模型。
- 项目工作台 -> 项目设置：项目级默认 Provider 策略。

## 前置条件

账号必须登录。未登录时，项目、工作台、模型配置、账号安全都不可用。

## 操作步骤

1. 点击顶部账号入口。
2. 在个人资料确认邮箱和账号状态。
3. 在安全设置启用或停用 MFA。
4. 在登录会话查看设备和最近活动。
5. 在全局设置选择托管 Provider 和默认模型。
6. 若项目有默认 Provider，以项目设置为准；个人全局设置作为补充。

## 输入示例

| 场景 | 检查点 |
| --- | --- |
| 没有可用模型 | 全局设置是否选择托管 Provider |
| 进入项目权限不足 | 项目成员列表是否包含当前账号 |
| 登录后又被踢回首页 | Cookie 会话是否过期 |
| MFA 无法验证 | 时间同步和认证器验证码 |

## 预期输出

| 操作 | 结果 |
| --- | --- |
| 保存全局设置 | 本地偏好写入托管 Provider ID 和默认模型 |
| 测试托管配置 | 返回连接成功或明确错误 |
| 修改安全设置 | 账号会话和 MFA 状态更新 |
| 退出登录 | 回到登录或官网入口 |

## 映射关系

| 配置来源 | 使用位置 |
| --- | --- |
| 全局 Provider | 普通工作台生成任务 |
| 项目默认 Provider | 项目内生成任务优先使用 |
| 成员角色 | 项目设置、成员管理、危险操作 |
| 登录会话 | 是否能访问受保护页面 |

## 常见问题与处理

- 顶部没有账号入口：先登录。
- Provider 列表为空：联系管理员或教师确认是否分配托管配置。
- 测试托管配置失败：查看错误消息，可能是模型不可用、额度不足或供应商故障。
- 项目设置不能编辑：当前角色可能是 viewer，只能查看不能管理。
