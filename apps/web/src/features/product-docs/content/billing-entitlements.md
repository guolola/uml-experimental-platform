# 生成权益、购买与订单处理

## 适用场景

你需要查看剩余生成次数、购买次数包、确认订单状态，或继续一个尚未完成的支付宝订单。

## 入口位置

- 官网或顶部导航的[价格方案](/pricing)。
- 账号入口中的[账户账单](/account/billing)。
- 生成操作提示“权益不足”时的购买入口。

![权益余额与订单历史](/help/images/docs-billing.png)

## 权益规则

| 来源 | 是否扣平台次数 | 说明 |
| --- | --- | --- |
| 邮箱验证赠送 | 是 | 新用户邮箱验证后赠送 30 次，有效期 30 天 |
| 平台次数包 | 是 | 价格、次数和有效期以后端 SKU 为准 |
| 个人自配 Provider | 否 | 使用自己的 API Key，费用由供应商账号承担 |
| 系统或项目 Provider | 是 | 每次生成按权益账本预占、确认或失败释放 |

## 购买次数包

1. 打开价格方案或账户账单。
2. 选择次数包并确认订单。
3. 生产环境通过 EPay 聚合支付宝跳转完成付款；本地开发使用 mock 支付。
4. 支付成功后回到平台，页面会查询订单并刷新权益余额。
5. 在账户账单中检查订单状态、次数、金额和有效期。

## 继续待支付订单

订单仍为“待支付”且没有过期时，账户账单会显示“继续支付”。点击后会沿用原订单号重新获取支付表单，不会重复创建一笔权益订单。

以下订单不能继续支付：

- 已支付、已关闭、失败或退款中的订单。
- 已超过有效支付时间的订单。
- 不属于当前账号的订单。

## 订单状态

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 待支付 | 支付尚未完成 | 点击“继续支付”或等待状态刷新 |
| 已支付 | 回调验签并成功发放权益 | 检查余额和权益有效期 |
| 已过期/已关闭 | 已不能继续支付 | 重新创建订单 |
| 失败 | 支付网关或订单校验失败 | 查看提示后重新购买 |
| 退款处理中/已退款 | 后台正在处理或已完成退款 | 查看订单历史，不要重复支付 |

## 常见问题与处理

- 支付完成但余额未更新：回到账户账单刷新订单；平台会查询支付状态并幂等发放权益。
- “继续支付”失败：确认订单仍是待支付且没有过期，再检查支付网关是否可用。
- 重复回调会不会重复加次数：不会，订单和权益发放按订单号保证幂等。
- 个人 Provider 为什么没有扣次数：个人 Provider 使用用户自己的密钥，不经过平台托管模型权益。
- 页面金额与宣传不一致：实际价格、次数和有效期始终以后端返回的 SKU 为准。
