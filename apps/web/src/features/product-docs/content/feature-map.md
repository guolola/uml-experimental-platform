# 页面入口与全链路映射

## 适用场景

你想知道某个功能在哪里、产物叫什么、失败时应该回到哪个页面排查。这个页面是目录中的“地图”。

## 入口位置

- 顶部导航：项目、考试、使用文档。
- 项目首页：项目列表和新建项目。
- 项目工作台：需求、图、设计、代码、测试、说明书。
- 项目抽屉：生成任务、运行历史、成员、项目设置、文档中心。

## 前置条件

你需要至少进入一个项目。没有项目时只能查看文档和官网信息，无法看到项目工作台产物。

## 操作步骤

1. 从项目首页进入“图书馆预约系统”。
2. 先用左侧主工作台完成需求、图、设计、代码、测试、说明书。
3. 生成时打开顶部“生成任务”观察状态。
4. 复盘时打开运行历史。
5. 管理项目时打开右侧项目抽屉。

## 输入示例

```text
我要找“AI 修复”在哪里：先打开需求页，再看规则列表中的质量提示和修复候选。
我要找“模型详情页”在哪里：先打开图或设计图，再点击元素或详情入口。
```

## 预期输出

| 想做的事 | 页面入口 | 结果 |
| --- | --- | --- |
| 创建实验空间 | 项目首页 -> 新建项目 | 项目和成员权限 |
| 整理需求 | 需求页 | 需求规则和基线 |
| 查看 UML | 图分组 | PlantUML、SVG、模型详情 |
| 推导设计 | 设计页 | 设计模型和追踪矩阵 |
| 生成原型 | 代码页 | 文件树、预览、诊断 |
| 做测试 | 测试页 | 测试用例和覆盖关系 |
| 出说明书 | 说明书页 | DOCX、版本、下载 |
| 查失败 | 生成任务、运行历史 | 阶段错误和证据 |

## 映射关系

| 上游 | 中间产物 | 下游 |
| --- | --- | --- |
| 需求文本 | 需求规则 | UML、测试、说明书 |
| 需求规则 | 需求模型元素 | 设计模型、追踪矩阵 |
| 需求模型 | 设计模型 | 代码原型、设计说明书 |
| 设计模型 | 文件计划和代码 | 预览、质量诊断 |
| 运行任务 | RunSnapshot 和事件 | 历史恢复、报告导出 |

## 常见问题与处理

- 找不到功能：先按页面入口定位，再在当前文档搜索关键词。
- 不知道下一步：看“映射关系”的下游列。
- 不知道失败原因：先打开生成任务，结束后再看运行历史。
