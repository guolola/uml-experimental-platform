# 需求 UML 模型与图表查看

## 适用场景

需求规则确认后，你需要生成并查看需求阶段 UML，确认每类模型是否覆盖业务、数据、界面、部署和交互分析。

## 入口位置

- 需求页点击“生成 UML 模型”。
- 工作台左侧“图”分组打开具体模型。
- 模型页上方切换图表、模型详情、源码和追踪内容。

![需求 UML 图表查看截图](/help/images/docs-uml-overview.png)

## 前置条件

需求规则已经确认，且没有阻塞性质量提示。若生成按钮显示前置条件缺失，先回到需求页处理。

## 操作步骤

1. 在需求页选择需要生成的模型类型。
2. 点击生成，打开项目顶部“生成任务”观察阶段进度。
3. 在侧边栏“图”下打开对应模型。
4. 检查 SVG 是否成功渲染，必要时查看 PlantUML 源码。
5. 点击元素进入模型详情页，查看元素、关系和追踪矩阵。

## 输入示例

| 输入 | 示例 |
| --- | --- |
| 已确认规则 | 学生登录后可以查询空闲座位 |
| 模型选择 | 用例模型、领域概念模型、总体业务流程 |
| 生成目标 | PlantUML、SVG、模型详情、追踪矩阵 |

## 7 类需求模型

| 模型 | 用途 | 示例 |
| --- | --- | --- |
| 功能结构图 | 分解系统功能和子功能 | 预约、签到、通知、管理 |
| 总体业务流程 | 展示跨角色流程和异常分支 | 查询座位 -> 提交预约 -> 通知 |
| 用例模型 | 展示角色、用例和系统边界 | 学生、管理员、预约、维护座位 |
| 领域概念模型 | 展示实体、属性和关系 | Student、Seat、Reservation |
| 原型界面关系 | 展示页面和入口跳转 | 首页、预约页、管理页 |
| 部署需求模型 | 展示节点、约束和外部服务 | Web、API、数据库、通知服务 |
| 需求分析模型 | 按用例事件流分析交互 | 学生预约座位的时序 |

## 预期输出

生成成功后，每类 UML 都会尽量形成结构化模型、PlantUML 源码、SVG 图表和元素级追踪数据。后续设计页、测试页和说明书页会读取这些模型作为输入。

## 映射关系

| 来源 | 生成物 | 下游用途 |
| --- | --- | --- |
| 需求规则 | 结构化模型 JSON | 模型详情页和追踪矩阵 |
| 结构化模型 | PlantUML | SVG 渲染和说明书嵌图 |
| SVG 图 | 图表查看 | 课程验收和设计输入 |
| 模型元素 | 追踪条目 | 设计模型、测试和说明书引用 |

## 常见问题与处理

- SVG 没出来：查看生成任务里的 `generate_plantuml` 和 `render_svg` 阶段。
- 某类模型缺失：确认生成时是否勾选，或该模型是否被前置失败跳过。
- PlantUML 报错：平台会尝试修复，失败后可查看错误并重新生成。
- 图太复杂：优先看元素列表和模型详情，不只依赖图片。
